#### What I work on

- **Backend & messaging:** NestJS microservices, NATS and RabbitMQ, webhooks,
  idempotent upserts, retries and recovery for background jobs
- **Data:** PostgreSQL (Prisma, migrations), MongoDB aggregation, Redis, ETL into
  reporting databases
- **Operations:** Docker, Kubernetes (Helm, rollouts, kubectl debugging),
  OpenTelemetry, GitHub Actions
- **Frontend:** Angular (v12 → v21), React, Next.js
- **AI-assisted engineering:** early adopter; Claude Code and Cursor day to day,
  local LLMs when code must stay on-premise. Plan first, review every generated
  line, test what matters
